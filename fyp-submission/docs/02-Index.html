5. Viewing diagrams

Every diagram in this package is written as Mermaid code (```mermaid fences) directly inside the Markdown source. They will not render as pictures in a plain-text editor or an unconfigured preview:

  • GitHub renders Mermaid natively in any .md file.
  • VS Code renders it with the "Markdown Preview Mermaid Support" extension installed.
  • The HTML build (pdf/ and the .html set) has every diagram pre-rendered to inline SVG — this is the reliable fallback if your viewer doesn't support Mermaid.
  • The Word thesis uses the pre-rendered PNGs in diagrams/, since Word cannot render Mermaid at all.

Every diagram in this package was render-tested against real mermaid.js before being shipped — see the QA note at the bottom of 00-Handover.md's revision history if you need to re-validate after an edit.

python make_package.py --docs-dir fyp-submission/docs --project-slug TrustLens

Run in this exact order — each step depends on the one before it. Full script options: pass --help to any of them.
